# Ping - Connect with Family 👋

A beautiful, responsive social app for connecting with family on Fomilo. Built as a Progressive Web App (PWA) with offline support.

![Ping App Preview](assets/screenshots/preview.png)

## ✨ Features

- 🔐 Secure authentication with localStorage persistence
- 📱 Fully responsive mobile-first design
- 🔄 Offline support via Service Worker
- 📸 Image upload with preview & drag-and-drop
- 💬 Real-time messaging interface
- ❤️ Like posts with animations
- 🎨 Beautiful gradient stories section
- ♿ Full accessibility support (ARIA, keyboard nav)
- 🌙 Reduced motion support
- 🔔 Toast notifications for user feedback

## 🚀 Quick Start

### Option 1: Local Development
```bash
# Clone the repository
git clone https://github.com/yourusername/ping-app.git
cd ping-app

# Open index.html in your browser
# Or use a local server:
npx serve .
# Then visit http://localhost:3000
```

### Option 2: Deploy to GitHub Pages
```bash
# In your repository settings:
# Settings → Pages → Source: Deploy from branch → main → /root
# Your app will be live at: https://yourusername.github.io/ping-app
```

### Option 3: Deploy to Netlify/Vercel
1. Connect your GitHub repo to [Netlify](https://netlify.com) or [Vercel](https://vercel.com)
2. Set build command: (leave empty)
3. Set publish directory: `.`
4. Deploy! 🎉
